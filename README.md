# Space Samurai

Neon cyber-samurai action game for the browser.

Warm up in a dojo, walk into a street fight, steal the enemy ship, and fly a small asteroid belt with full 6DOF controls.

**Stack:** Three.js / WebGPU · phone + desktop · assets from [Free Asset Index](https://canop3n3r.github.io/free-asset-index/)

**Live:** https://canop3n3r.github.io/space-samurai/ (after first deploy)
